### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

Check your installed versions:

```bash
node --version
npm --version
git --version
```

### Installation

Clone the repository:

```bash
git clone https://github.com/Krina2310/Krina-portfolio.git
```

Move into the project directory:

```bash
cd Krina-portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL shown in the terminal. It is usually:

```text
http://localhost:5173
```

## Adding Your CV

Place your CV in the `public` folder with the following filename:

```text
public/resume.pdf
```

The portfolio's CV button will then open the file at:

```text
/resume.pdf
```

## Customisation

To personalise this portfolio, update the following:

- Your name in `src/App.tsx`
- Your introduction and biography
- Project titles and descriptions
- GitHub project links
- LinkedIn profile URL
- Email address
- Education details
- Experience details
- Skills list
- CV file in the `public` folder
- Profile image in `public/images`

## Deployment

This project can be deployed using:

- Vercel
- Netlify
- GitHub Pages

For Vercel:

1. Push the project to GitHub.
2. Sign in to Vercel using GitHub.
3. Import the `Krina-portfolio` repository.
4. Keep the default Vite settings.
5. Deploy the project.
